## 🎯 Что такое JKG

JKG — это memory-движок для AI-агентов, который решает три смертельные ошибки всей индустрии AI-памяти:

| Ошибка индустрии | Решение JKG 3.0 |
|----------------|-----------------|
| **1 слой** (граф ИЛИ embeddings) | **Гибрид**: граф + embeddings → RRF fusion |
| **Дрейф** (две базы рассинхронизируются) | **Одна БД**: SQLite + sqlite-vec |
| **Однонаправленный поток** | **Двусторонний мост**: граф↔embeddings |

## 🚀 Быстрый старт

```bash
# Установка
pip install jkg

# Инициализация
jkg init

# Запомнить факты
jkg remember "Меня зовут Алиса, я CTO в Acme Corp"
jkg remember "Acme Corp — стартап в сфере AI, 50 сотрудников"

# Спросить
jkg ask "Где работает Алиса?"
# → Алиса работает в Acme Corp

# Гибридный поиск (синонимы!)
jkg ask "Расскажи про rivals компании Алисы"
# → Находит "конкурентов" через семантический поиск,
#   даже если в базе только "competitors"

# Статистика
jkg stats
# → 12 entities, 15 facts, 23 relations, 15 vectors
```

## 🔧 Возможности

| Команда | Что делает |
|---------|-----------|
| `remember "текст"` | Извлекает сущности (DeepSeek LLM) → сохраняет атомарно: граф + вектор |
| `recall "запрос"` | Гибрид: BM25 + KNN + граф BFS → RRF fusion |
| `ask "вопрос?"` | recall → LLM реранк → синтез ответа |
| `traverse "имя" 3` | BFS-траверсал от сущности на глубину 3 |
| `path "A" "B"` | Кратчайший путь между сущностями |
| `bridge` | Двусторонний мост: PageRank↔confidence, embeddings↔связи |
| `stats` | Статистика: сущности, факты, связи, вектора, orphan'ы |

## 📦 Зависимости

- `sqlite-vec` — векторный поиск внутри SQLite
- `sentence-transformers` — локальные embeddings (all-MiniLM-L6-v2)
- `deepseek-chat` — LLM для extraction и реранка (можно заменить на любой)

**0 external APIs для recall. Всё локально.**
